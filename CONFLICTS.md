# CONFLICTS.md

This file records every conflict found between config files during the
consistency refactor, plus the decision for each. Nothing was resolved
silently. A conflict stays listed here even after the files were fixed,
so the reasoning stays auditable.

Location: this file lives at the repo root, not in `muse/`, because it is
a repo-level decision record about the standing files, not a standing
file itself.
